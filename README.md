# 优秀融媒体 H5 案例分享

融媒体课程作业网站：四个经典商业 H5 案例的研究与拆解，覆盖 **活动运营、品牌宣传、产品推广、总结报告** 四种类型。

纯静态站点，零依赖：HTML + CSS + 原生 JavaScript，无需构建步骤。

## 在线案例来源

| 类型 | 案例 | 出品方 | 链接 |
|---|---|---|---|
| 活动运营型 | 睡姿大比拼 | 网易新闻 × 网易哒哒 | <http://news.163.com/special/fdh5_sleeping_19/> |
| 品牌宣传型 | 全景故宫 | 故宫博物院 | <https://pano.dpm.org.cn/> |
| 产品推广型 | 糟糕，心动了（小米10青春版） | 小米 | <https://s1.mi.com/m/webgl/mi10youth/> |
| 总结报告型 | 2022 音乐旅途报告 | QQ音乐 × Billboard | <https://y.qq.com/m/year_personal_2022/index.html> |

> 所有案例链接均已验证国内可直接访问（HTTP 200）。案例截图及内容版权归原出品方所有，仅作课程学习研究用途。

## 目录结构

```
src/
├── index.html        # 页面结构（单页）
├── css/style.css     # 全部样式（含响应式）
├── js/main.js        # 交互脚本（无第三方库）
└── img/              # 案例截图素材（已裁剪手机状态栏）
```

## 页面内容

- **首屏**：主题 + 四类案例标签
- **案例区**：每类案例一节（手机样机截图展示 + 玩法拆解 + 类型启示 + 原案例链接）
- **对比表**：四类打法横向对比（核心目标 / 关键交互 / 传播动力）
- **总结启示**：共性、差异、本质三条
- **页脚**：案例链接汇总 + 版权声明

## 本地预览

任选其一，在 `src/` 目录下：

```bash
python3 -m http.server 8080
# 或
npx serve .
```

然后访问 <http://localhost:8080>。

## 部署

纯静态文件，把 `src/` 目录整体上传到任意静态服务器 / Nginx 站点根目录即可，例如：

```bash
# Nginx：将 src/ 内容放到站点根目录
root /var/www/h5-cases;
```

无需 Node、无需构建，直接托管静态文件即可。

## 交互特性

- 滚动显现动画（IntersectionObserver）
- 导航栏滚动变色 + 当前区块高亮
- 移动端汉堡菜单，全站响应式
- 回到顶部按钮
- 遵循 `prefers-reduced-motion` 减动效偏好
