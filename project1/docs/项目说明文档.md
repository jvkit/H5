# 项目一说明文档：2026 校园星光音乐节 · 报名宣传 H5

> 命名：班级—组号—项目一校园活动报名宣传H5（提交时替换班级与组号）

## 一、主题

校园活动报名宣传 H5——「2026 校园星光音乐节」。
以一场虚构的校园音乐节为载体，完成活动宣传、内容分支浏览与在线报名闭环。

## 二、目标受众

本校在校师生，主要为 18—24 岁本科生；使用手机竖屏浏览，单页停留时间短，偏好强视觉、轻交互的宣传形式。

## 三、宣传目的

1. 告知：让师生快速了解音乐节的时间、地点、流程与演出阵容；
2. 转化：通过 30 秒即可完成的报名表单，把"感兴趣"转化为"报名到场"；
3. 留存：报名回执编号 + 入场短信，形成活动与受众的后续触点。

## 四、作品规格

- 竖屏 H5，舞台 640×1136 像素，JS 等比缩放适配各尺寸手机
- 页面共 6 页（P1—P6），弹窗 2 个（不计入独立页面）
- 主色三种：夜空紫 / 霓虹粉 / 星光青；按钮样式统一
- 字号规范：大标题 96px、页面标题 44px、正文 26px、注释 20px

## 五、页面清单

| 页面 | 名称 | 主要内容 |
|---|---|---|
| P1 | 封面 | 活动主视觉、时间地点、进入按钮 |
| P2 | 活动介绍（分支选择页） | 三个分支按钮：活动详情 / 演出阵容 / 立即报名；开演倒计时 |
| P3 | 活动详情 | 时间安排、场地分布、报名须知弹窗入口 |
| P4 | 演出阵容 | 6 组嘉宾卡片，点击弹出图文介绍弹窗 |
| P5 | 报名表单 | 姓名、手机号、学院、意向区域；必填与格式校验 |
| P6 | 报名成功反馈页 | 回执编号、姓名、区域回显，返回首页 |

## 六、四项功能与实现方式（汇报用）

任务书要求至少三项，本作品完成**全部四项**：

| 功能 | 触发条件 | 行为与实现 |
|---|---|---|
| 分支跳转 | 点击 P2 的三个分支按钮 | 不同按钮跳转不同页面（P3 / P4 / P5），看到不同内容；非线性顺序滑动 |
| 弹窗交互 | P3 点击"查看报名须知"；P4 点击嘉宾卡片 | 弹出信息层；弹窗内设"我知道了 / 关闭"按钮，点击关闭；点击遮罩也可关闭 |
| 音频控制 | 点击右上角"音乐"按钮 | 背景音乐播放 / 暂停，可反复操作；音乐由程序合成，无外部音频文件、无版权问题 |
| 表单闭环 | P5 点击"提交报名" | 姓名、手机号、意向区域必填校验；手机号 11 位格式校验；校验通过跳转独立反馈页 P6 并生成回执编号 |

## 七、素材说明

- 视觉元素（星点、唱片、头像色块、图标）均为 CSS / 程序绘制，无外部图片素材；
- 背景音乐为 Web Audio 实时合成的原创程序旋律，无音频文件、无版权风险；
- 全部内容离线可用，适合课堂无网环境演示。

## 八、测试记录

手机视口（390×844）实测：四项功能逐项点击通过；空表单与错误手机号均被拦截并提示；提交成功跳转反馈页；无横向滚动、无文字溢出、无 JS 报错。
